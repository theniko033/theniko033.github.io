# Niko — @theniko033

## Run it in VS Code

1. Extract this folder.
2. Open the folder in VS Code: **File → Open Folder**.
3. Open `index.html`.
4. Install the **Live Server** extension.
5. Right-click `index.html` → **Open with Live Server**.
6. Edit and save. The browser will update automatically.

### What to edit
- `index.html` → name, bio, link URLs, favorite titles.
- `style.css` → colors, sizes, spacing, glass effects, animations.
- `assets/` → profile/favorite images.

Keep this structure:
- `index.html`
- `style.css`
- `assets/`

The images are local, so they won't depend on image hotlinks.

## Publish for free with GitHub Pages

Upload these files to a GitHub repository, then:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**
